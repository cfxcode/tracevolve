# 代码维护任务域：实现与真实运行记录

本轮按用户确认新增代码维护任务域，保留 Codex 运行时和文本 Skill 修改范围。
**代码任务接入与证据回放已经运行；真实自优化闭环仍未完成验收。**

## 实现及离线验证

- 17 个独立的、人工构造的小型 Python 维护问题模板。包含接口迁移、数值边界、
  事务、缓存、文档补丁和配置引用；这不是生产仓库缺陷频率研究。
- 模型可读取／修改任务源文件，执行不可改动的公开示例，并补充自己的案例。
  提交产物与 Prompt／Skill 候选分别保存；宿主在模型会话结束后独立验收。
- macOS Seatbelt 代码运行边界：拒绝宿主文件读取、网络连接、创建子进程。
  沙箱缺失时明确失败；不使用无限制代码执行作为替代。
- 代码研究在模型调用前冻结全部任务并验证参考修复、初始缺陷和重命名语义。
  许可与默认指针按代码任务族隔离；v2 文件写入要求当前内容哈希。
- 真实代码的工具回放与重新验收均已执行。发布、后续选择、暂停、复验及回滚
  的新任务族路径仅通过明确标记为 synthetic 的离线测试，不能当作真实闭环。
- 本地离线测试为 **119 项原版 + 109 项项目测试 = 228 项**。CI 同时覆盖
  Linux 和 macOS；Linux 跳过需要实际 Seatbelt 的测试。

复合轮的文档补丁任务通过全部 **27 项宿主检查**，模型自行补充的 **32 项案例**
也全部通过。总计 **7 次真实 Codex 会话、77 个原始文件**，全部具备加载回执，
请求／事件／结果核对与归档源码回放通过，没有不确定执行。

`target_met=false`、`data_complete=false`。32／24 次会话上限没有耗尽；

保留集、发布或契约变化复验，也没有启动五候选小试。

## 用量与限制

观察到的输入 Token 为 **512,270**，其中缓存输入 **429,952**；输出 Token
**8,361**，另记录 reasoning_output_tokens **458**。缓存输入属于输入字段，
不能再次相加。会话总耗时 **421.31 秒**。这些是 CLI 可观察字段，不能推导
内部 HTTP 请求次数；订阅美元费用为 **null**，不声明美元预算合规或等成本比较。

新增代码域没有使用或伪装成资源任务 v0.2.1 导出，也不代表第二运行时、自动多轮
升级、Harness 脚本修改或完整 P1b 已实现。当前固定模型对这些小型维护问题仍能
全部完成。下一阶段若继续校准，应使用有真实上下文与跨模块约束的仓库级问题，
冻结独立回归检查后再运行；不得把初始缺陷或人为塞入的候选当作模型失败。
